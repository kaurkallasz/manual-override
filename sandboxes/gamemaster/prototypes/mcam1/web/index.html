Preparing a trained-model update

Train and quantize a model for ESP32-S3, integrate its inference code into the XIAO firmware, and compile a complete build. Keep the bulk UVC descriptors, controls protocol 1, detection protocol 1 and the 4 MiB factory partition. MCAM1 supports model and class names from compatible detection replies.

Package those compiled images with the module’s tools/package_firmware.py, or upload the original Lab release ZIP. The validator checks hashes and image layout; it cannot establish a custom model’s accuracy or hardware compatibility. Use builds from a source you trust. The bundled ai-v1 remains available for recovery.

This utility targets the XIAO ESP32S3 Sense / OV3660. Firmware for ESP32-CAM, other sensors, encrypted boards, OTA or separate model partitions needs a different flashing profile.
